{{ view.period_label }}的账({{ view.report_rows | length }} 格)

这几个数怎么算的

轮次数的是你说的话(user/message);调用是模型被调了几次 —— 一轮里它可能被调好几次(工具往返),所以这两个数不相等是正常的。

命中率 = 命中 ÷(命中 + 未命中),只统计有 token 账的那些调用。 「缓存省下」是拿实测命中率估的:不做缓存要按未命中单价付全部输入。

≈花费 = token 钱 + 联网请求费。token 按**每条事件自己的时刻**分档: 工作日 9:00-12:00、14:00-18:00(北京时间)是高峰,其余时间与周末**半价** —— ⚠️ 法定节假日没单独扣,那几天按高峰算,所以这个数是**略微高估**的估计值,真实账单以服务端为准。 联网(搜/抓)每次**成功**请求 0.005 元,失败与无结果不计费。
