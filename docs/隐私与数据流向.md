# 隐私与数据流向

**一句话**：数据默认不出你的机器；出网的只有"你必须发给模型才能得到回答"的那部分。

## 数据存在哪

| 内容 | 位置 | 说明 |
|---|---|---|
| 对话、账目、日程、健康、错题、笔记 | `data/assistant.db` | SQLite，STRICT 表 |
| 长期记忆、摘要、事实 | `data/memory.db` | 与领域库分开，便于单独备份/清理 |
| 照片、录音、生成的音频 | `data/media`、`data/artifacts` | 原文件 |
| 每轮发给模型的上下文快照 | `data/trace/context.jsonl` | 纯观测数据，不进对话历史 |
| 密钥 | `data/` 下的凭据文件或 `.env` | 页面里填的密钥加密存库 |

删除 = 删文件。没有云端副本，也没有"注销账号"这一步。

## 什么时候会出网

| 触发 | 出网内容 | 接收方 |
|---|---|---|
| 你发一条消息 | 消息 + 装配进去的记忆/上下文 | 你配置的模型服务（默认 DeepSeek） |
| 让它看图片 / 截图 | 图片 | 模型服务的视觉接口 |
| 语音合成 | 要朗读的文本 | 阿里云百炼（仅在配了 key 时） |
| 联网搜索 / 抓取 | 检索词、目标 URL、页面 | 默认**关闭**；开启后走 DeepSeek 官方 search/fetch |
| 微信桥接 | 消息内容 | 微信（仅当你自己接了桥） |
| 日历订阅 | 日程内容 | 拉取那个订阅链接的人（链接即凭据） |

**没有**遥测、崩溃上报、使用统计、第三方统计 SDK。

## 敏感信息怎么处理

- 标为敏感的长期事实**不会进入提示词**，在页面上显示为占位符 —— 有测试钉住这条。
- 密钥在日志、页面、工具输出里一律掩码，只露首尾。
- 工具输出在注入模型前会加一行标记：外部内容按**资料**处理，不按指令处理。
- 截图工具只允许截本应用生成的页面，且禁止 `file://`（防止把本机任意文件画进画面再被模型读走）。

## 你的责任

- 别把 Web 裸奔到公网；要挂就加 HTTPS + 反代认证（见 `SECURITY.md`）。
- `/calendar/ics` 与 `/api/health/sync` 是为手机留的口子，链接/口令泄露等于数据泄露，可在页面上一键重置。
- 备份文件 `data/backups/` 里含完整数据库，别往公共网盘丢。
