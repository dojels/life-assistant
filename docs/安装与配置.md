# 安装与配置

## 环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| Python | 3.12+（推荐 3.14） | 开发与验收在 3.14 完成 |
| 操作系统 | Windows / Linux / macOS | Windows 有双击启动脚本；其余平台用命令行 |
| 磁盘 | ≥ 200 MB | 依赖约 100 MB，数据看你怎么用 |
| 网络 | 需要访问模型 API | 只有对话时才出网 |

## 安装

```bash
git clone <repo-url> life-assistant
cd life-assistant
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -e .
cp .env.example .env
```

然后编辑 `.env`，至少填一项：

```ini
LA_LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=sk-你的密钥
```

不想联网/不想花钱，改成 `LA_LLM_PROVIDER=fake` 也能跑通全部页面。

## 启动

```bash
python -m la --web          # 默认 http://127.0.0.1:8765
python -m la --web 0.0.0.0:8765   # 局域网可访问（注意安全,见 SECURITY.md）
```

Windows 上也可以直接双击 `launcher.cmd`：它会把 Web 与已登录的微信桥接一起拉起来，
再双击一次是重启。子命令：`launcher.cmd status` / `logs` / `stop` / `task install`。

## 首次访问

第一次打开会跳到 **/setup**：建立一个家庭成员（管理员）并设置 **PIN**。
之后每次访问用 PIN 登录；忘记 PIN 用：

```bash
python scripts/reset_pin.py
```

数据始终在本机，PIN 只是防止同一台电脑上别人随手打开。

## 配置项

完整清单在 [`.env.example`](../.env.example)，每一项都有注释。分组速查：

| 组 | 变量 | 说明 |
|---|---|---|
| 模型 | `LA_LLM_PROVIDER` `DEEPSEEK_API_KEY` `LA_BASE_URL` `LA_MODEL` `LA_REASONER_MODEL` `LA_REASONING_EFFORT` | 兼容 OpenAI 风格接口的端点都能接 |
| 运行 | `LA_TIMEZONE` `LA_SESSION_ID` `LA_REQUEST_TIMEOUT` `LA_MAX_RETRIES` | 时区决定"今天" |
| 数据 | `LA_DATA_DIR` `LA_DATA_QUOTA_MB` | 默认 `./data` |
| 安全 | `LA_READ_ONLY` `LA_DIRECT_WRITE` | 只读开关 / 写入是否等确认 |
| 联网 | `LA_WEB_ENABLED` `LA_WEB_SEARCH_PROVIDER` `LA_WEB_FETCH_PROVIDER` | 出厂关闭 |
| 语音 | `LA_TTS_PROVIDER` `LA_TTS_VOICE` `DASHSCOPE_API_KEY` | 可选 |
| 手机 | `LA_CALENDAR_PUBLIC_BASE` `LA_HEALTH_PUBLIC_BASE` | 手机订阅日历 / 推健康数据用的公网地址 |

也可以不改 `.env`，直接在「设置」页里填模型与密钥（密钥加密后存库）。

## 数据、备份、迁移

所有状态都在 `LA_DATA_DIR`（默认 `./data`）：

```
data/
  assistant.db   领域数据 + 事件日志 + 回执
  memory.db      长期记忆、摘要池、会话
  media/         照片、音频等素材
  artifacts/     生成的文件（卷子、报告）
  trace/         每轮上下文快照（可关）
  backups/       自动备份
  logs/          运行日志
```

- **备份**：停服务，复制整个 `data/` 目录。
- **迁移**：把 `data/` 拷到新机器，其余重装即可。
- **重置**：删掉 `data/`，下次启动会重新建库（记录与素材一并消失）。

## 升级

```bash
git pull
pip install -e .      # 依赖有变时
python -m la --check  # 自检
```

数据库迁移在启动时自动执行，按 schema 版本号顺序推进，不需要手动操作。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 页面能开，回复报错 | `.env` 没填 key，或 key 无效；先 `python -m la --check` |
| 端口被占用 | `python -m la --web 127.0.0.1:8766` |
| 模型返回 400 且提到 schema | 工具 schema 与端点不兼容；把 `LA_MODEL` 换成默认值再试 |
| 语音没声音 | 未配 `DASHSCOPE_API_KEY`，会退回本地 SAPI 或静音并在结果里说明原因 |
| 手机订阅日历打不开 | 没配 `LA_CALENDAR_PUBLIC_BASE`，链接只有内网地址可用 |
