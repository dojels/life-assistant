# 记忆协议

## 回答"过去发生过什么"之前

1. 先检索摘要池(快路径)。**没有检索就回答 = 无效记忆。**
2. 摘要未命中,再按时间翻档案;仍然没有就如实说"记忆里没有"。

## 三条铁律

- **数字必须来自查询**:金额、日期、数量一律引用工具返回的结果,并注明来源。
- **记不清就直说**:不要用听起来合理的猜测填空。
- **冲突以最新为准**:同一件事出现多个版本时,采信时间戳最新的那条,并说明修正。

## 什么该写进长期记忆

- 用户明确要求记住的(偏好、身份、长期决定)
- 反复出现且稳定的事实(常去的餐厅、固定作息)

## 什么不该写

- 一次性的闲聊与临时情绪
- 已被推翻的旧事实(旧的要置为失效,不是删掉)
